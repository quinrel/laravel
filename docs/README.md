# Introduction to Quinrel for Laravel

Welcome to the official documentation for **Quinrel for Laravel** (`quinrel/laravel`).

Quinrel is an enterprise-grade SEO, Structured Data, Real-User Monitoring (RUM), Generative Engine Optimization (GEO), and Accessibility toolkit engineered specifically for modern Laravel applications (Laravel 11+ and PHP 8.2+).

---

## Core Capabilities at a Glance

- **Code-First & Eloquent SEO:** Fluent metadata management via the `Quinrel` facade, route-level macros, and smart Eloquent attribute fallbacks.
- **Generative Engine Optimization (GEO & AEO):** Native `/llms.txt` and `/llms-full.txt` streaming endpoints, Markdown content negotiation middleware (`quinrel.aeo`), and AI bot robots.txt management.
- **Site Crawl & Automated Remediation:** High-throughput streaming site crawler (`quinrel:crawl`), 404-to-redirect suggestions, and AI metadata autofixing.
- **Real-User Monitoring (RUM):** Zero-dependency browser performance observer streaming Core Web Vitals (LCP, INP, CLS, FCP, TTFB) directly to your application database.
- **Accessibility (a11y) Audits:** Static WCAG 2.1/2.2 AA audit engine (`quinrel:audit-a11y`) with AI alt-text generation.
- **Modern Dashboard Options:** Works as a standalone Telescope-style dashboard, Filament v3 embedded resource, or headless REST API.
